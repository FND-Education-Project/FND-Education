## In this module

- FND should be diagnosed through positive evidence and appropriate clinical reasoning—not merely because testing was unrevealing. Tests answer defined questions, and another condition may coexist with FND. (*citations* [1](#citation-1), [2](#citation-2), [3](#citation-3))
