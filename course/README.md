## About the course

The current pathway has **19 modules and 57 focused lessons**. It teaches foundations and safety, then attention and body-brain concepts, symptom description and Reference navigation, rehabilitation and pacing, followed by treatment and daily life.

Automatically generated lessons are live working drafts while the project lead develops human-authored versions. Publication checks cover evidence, safety, citations, navigation and technical behavior. Human authoring and two further lesson audits follow; this status is not independent clinical sign-off.
