This module separates three ideas that are often presented in one bite: what rehabilitation is, how to plan practice safely, and how to assess “rewiring” claims.

## In this module

- Rehabilitation can include practice, adaptation and other routes to participation.
- A practice plan should include immediate and delayed effects.
- Neuroplasticity does not prove that a program works or guarantee recovery.

Rehabilitation evidence differs by FND presentation and outcome. A plausible learning model is not the same as proof that one program works for everyone. (*citations* [1](#citation-1), [2](#citation-2), [3](#citation-3))
