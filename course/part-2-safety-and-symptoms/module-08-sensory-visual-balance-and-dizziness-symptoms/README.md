Sensory, visual and dizziness symptoms often overlap in daily life, but they are not all the same problem. This module separates assessment, access and rehabilitation into smaller pieces.

## What this module teaches

- Functional sensory and visual diagnoses need positive clinical evidence and appropriate assessment of other causes. (*citations* [1](#citation-1), [2](#citation-2))
- “Dizzy” can describe several different experiences; PPPD has specific criteria. (*citation* [3](#citation-3))
- Accommodation can create access now, while gradual rehabilitation remains a separate choice.
- Treatment evidence is early or mixed, so the plan should be individualized and reviewed. (*citation* [4](#citation-4))
