Functional seizures are real, involuntary episodes. This module separates diagnosis, immediate safety, treatment and daily-life planning so you can read only the piece you need.

## What this module teaches

- Diagnosis should use positive evidence about the person’s typical event. (*citation* [1](#citation-1))
- Functional seizures and epilepsy can coexist. (*citation* [1](#citation-1))
- A shared plan can protect safety without restraint or unnecessary treatment.
- Treatment evidence is mixed, and meaningful progress can include more than seizure count. (*citation* [2](#citation-2))
