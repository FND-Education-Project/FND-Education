Speech, voice, swallowing and breathing symptoms can affect safety, dignity and connection. This module keeps immediate safety, symptom treatment and communication access visible as separate needs.

## What this module teaches

- Functional communication symptoms can be diagnosed using positive clinical features. (*citation* [1](#citation-1))
- Swallowing and breathing safety must be assessed before a symptom is assumed to be functional.
- Speech-and-language treatment can be useful, but much of the guidance is professional consensus rather than trial evidence. (*citation* [1](#citation-1))
- Communication access should begin now and should not depend on spoken recovery.
