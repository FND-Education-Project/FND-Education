# Module 11: Pain, Migraine, Fatigue, and Sleep

> **Working draft:** This page was automatically generated and is looking for [contributors and reviewers](https://fnd-education-project.github.io/FND-Education/).

Pain, migraine, fatigue and poor sleep can each be disabling. They can also amplify one another. This module gives each problem its own short page before bringing the pattern together.

## What this module teaches

- Pain is common alongside FND, but it may have several causes and deserves its own assessment.
- Migraine is a neurological disorder that can coexist with and sometimes trigger FND symptoms.
- Fatigue is not laziness. Its causes can include FND, sleep loss, pain, medication and other medical conditions.
- Post-activity worsening describes a pattern; it does not by itself establish FND, ME/CFS or another diagnosis.
- Sleep complaints and sleep disorders are not the same thing. Treatable disorders should not be missed.
- When symptoms interact, change one part of the loop at a manageable dose. (*citations* [1](#citation-1), [2](#citation-2), [3](#citation-3), [4](#citation-4))
