# Crossword Answer Keys

This folder contains completed versions of the crosswords. The answer keys are kept apart from the puzzles so a person can choose when to see them.

## In this folder

- **[Puzzle index](../../puzzle-index.md)** — match each answer key with its puzzle and course material.
- **[Easy crosswords](../easy/README.md)** — find shorter or more strongly supported versions.
- **[Normal crosswords](../normal/README.md)** — find the current crossword collection.
