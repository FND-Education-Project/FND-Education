# Crosswords

These printable crosswords revisit words and ideas from the course. Easy and normal puzzles are kept separate, while answer keys have their own folder so they are not opened accidentally.

## In this folder

- **[Easy](easy/README.md)** — shorter or more strongly supported crosswords.
- **[Normal](normal/README.md)** — crosswords with more clues or a broader vocabulary.
- **[Answer keys](answer-keys/README.md)** — completed versions of the available crosswords.
- **[Puzzle index](../puzzle-index.md)** — see which course pages each crossword supports.
