SEARCH

Search the FND Education Project

Search across the published course, Reference Library, glossary, booklets, and project information.

Search can recognize accepted FND terminology, abbreviations, spelling variants, and some plain-language concepts. Because of that, a useful result may not contain the exact words you typed in the visible excerpt. Search helps locate pages; it does not diagnose symptoms.

Search privacy

Search runs in your browser using a static index downloaded with this website. The FND Education Project does not use search analytics, does not save your search terms, and does not sell or share them.

This site does not use its own tracking cookies. With JavaScript enabled, searches started from the site header are placed after the # in the address so the search words are not sent to the website host as part of the page request. Your browser may still keep its own local history, and any external site you open has its own privacy practices.
