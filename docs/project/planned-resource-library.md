# Planned Resource Library

The project is intended to be useful during real appointments, daily activities, and symptom episodes—not merely something to read once.

Planned downloadable or printable resources include:

- one-page FND explanation;
- positive-diagnosis question sheet;
- symptom and comorbidity map;
- functional episode plan;
- emergency information card;
- appointment preparation sheet;
- medication and treatment record;
- activity and pacing planner;
- cognitive-support toolkit;
- support-person agreement;
- setback and relapse plan;
- [FND terminology glossary](../../glossary/README.md);
- evidence-rated treatment directory;
- misinformation and exaggerated-claim checklist.

Each resource should state its purpose, intended audience, limitations, creation or review date, and the research, guidance, or lived experience that informed it.
