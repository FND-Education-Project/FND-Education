**Review date:** October 3, 2026. **Scope:** the [collection overview](../../reference/biopsychosocial-experiences/README.md) and its six focused pages. Source verification and editorial checks are complete; human clinical, lived-experience, supporter, disability-community, rehabilitation and accessibility review remain pending. This record does not represent clinical approval.

## Changes

- Corrected seven shared bibliography records against primary publication records. Applied the same metadata corrections to ten course pages using these sources; their educational prose was not revised.
- Added study designs, participant numbers and limitations to standalone citation tables. Distinguished reviews, proposed models, expert consensus, qualitative interviews, observational questionnaires and an uncontrolled service evaluation.
- Clarified that emotional-processing research does not establish universal irritability or individual causation. Practical scripts and planning examples are project suggestions, rather than tested interventions.
- Corrected the stigma-study description and retained the education evaluation’s absence of significant stigma improvement.
- Qualified equipment and sensory advice to reflect the actual occupational-therapy consensus. Removed an unsupported diagnostic list attributed to qualitative studies.
- Strengthened medication-review and new-symptom wording, removed blanket assurance that a public episode is safe, and linked delayed activity worsening to existing pacing guidance.
- Added short, located excerpts with figure-to-source mapping. Preserved stable IDs and added the existing Bennett review where clinical claims needed direct support.
- Standardized audience-menu separators so the generator supplies Previous/Next navigation after each audience section. Added explicit Previous links to the authored chain.

## Checks and remaining review

- Site preparation and generated-source validation pass: 98 course pages, 294 public Reference pages and 399 public routes. No public page was added, moved or removed.
- Citation numbers have unique table anchors. Four-column tables map each page’s three evidence-note figures to sources.
- Generated collection pages contain navigation after all three audience sections. The authored chain runs through the overview and six topics, with matching Previous links.
- Full Jekyll build and rendered-artifact validation are required on the pull request before merging. Local Ruby/Bundler are unavailable.
- Human reviewers should assess practical scripts, equipment nuance, sensory protection, care relationships and accessibility. Source verification does not complete those reviews.
