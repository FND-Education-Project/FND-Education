# Accessibility Standards

FND itself can make reading and navigating educational material difficult. Cognitive symptoms, migraine, visual sensitivity, fatigue, pain, motor disability, hearing problems, and sensory sensitivity should be considered throughout the design.

The project will aim for:

- short, readable paragraphs;
- a predictable page structure;
- the same four on-page section links repeated before each major section;
- descriptive headings;
- plain language without removing necessary medical precision;
- strong contrast without unnecessary visual clutter;
- resizable text and layouts that remain usable when zoomed;
- keyboard-accessible navigation in any future website;
- visible focus indicators;
- meaningful link text rather than repeated “click here” links;
- descriptive alternative text for meaningful images;
- captions and transcripts for audio and video;
- printable and low-ink summaries;
- content that remains understandable with screen readers;
- important information conveyed in text rather than colour alone;
- minimal unnecessary animation, motion, flashing, or autoplay;
- controls for any necessary motion or media;
- downloadable material that follows the same accessibility principles.

Accessibility should be checked during authoring and review, not added only after publication.
