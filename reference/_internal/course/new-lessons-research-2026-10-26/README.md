## Authoring sequence

Read the source register, relevant brief and existing syllabus outline. Develop one Person section at a time for Robert’s editing, then the other audience sections. Include the project's wider health-professional audience where the established page template requires it. Preserve human-authored existing lessons. Use primary studies for specific findings, professional guidance for recommendations, and identify reviews/models accurately. Match source-use claims to what was retrieved; do not imply abstract/index access is a full-text appraisal.

No community quotations were selected in this batch. Add only verified, context-appropriate quotations from the project's provenance records in a later editorial step. Do not substitute invented dialogue for attributed lived experience.

## Publication boundary

Proposed numbers 16–30 are reading positions, not URLs or progress IDs. These files do not change the public course, account contracts, assets or learner records. All new public text still needs human review, citation-index/use-record registration, final links, audience structure and release QA. The reference library remains the destination for symptom-specific depth. Reading through these lessons is not a prerequisite for clinical care.
