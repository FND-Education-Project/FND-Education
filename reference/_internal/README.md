# Internal Reference Working Material

This folder contains repository-only editorial, review and production material for the Reference section.

**Publication rule:** everything under `reference/_internal/` is permanently excluded from the public website. The site generator must never copy or publish this folder. Public reader-facing pages must remain understandable without opening anything here.

If a document becomes reader-ready, move it out of `_internal` into the appropriate public Reference location instead of adding a publication exception.

## Unified CBT-informed booklet production pack

The [production-pack index](recovery-techniques/functional_seizures/unified_cbt_booklets/README.md) contains five planned booklet outlines plus five in-depth content-creator guides. These are authoring materials, not finished patient booklets.

The five planned booklets are:

1. Understanding Functional Seizures and CBT.
2. Discovering Your Seizure Pattern.
3. Skills for Warnings and Seizure Onset.
4. Returning to Activities and Independence.
5. Support, Setbacks, and Maintaining Progress.

Each outline defines what the future booklet should accomplish. Each content-creator guide explains the CBT concepts, functional-seizure applications, worked examples, visual possibilities and language cautions needed to draft it responsibly.

## Maintenance

When internal reference material is added in future:

1. Put it somewhere under `reference/_internal/`.
2. Link to it from other repository-only material as needed.
3. Do not add it to the public sitemap or public navigation.
4. Keep public pages independent of it.
5. Move it into the public Reference tree only after it has become reader-facing content.
