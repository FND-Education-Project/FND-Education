# Diagnostic Review — Essential Reading in Review Order

> **Internal editorial reading guide — October 7, 2026.** This file is a review aid, not a reader-facing clinical page. It is built from the sources currently cited in the diagnostic symptom, inventory and detailed-technique pages. It is **not an independent systematic literature search** and does not imply that uncited later studies, replications or conflicting evidence are unimportant.

## How to use this guide

Work down the symptoms in the same order as the diagnostic collection.

1. Read the **symptom-level sources first** to understand the clinical frame before judging individual claims.
2. Where a detailed technique page already exists, read its **technique-page sources next**, in citation order, before reviewing that page.
3. Then work through the **technique/inventory headings in order**. The papers listed under each heading are the sources currently attached to that technique's claims.
4. Tick a paper only after reading enough of the original source to check the claim being made. An abstract alone is not enough for a detailed methods, accuracy or limitation claim.
5. Record missing full text, later replication, contradictory evidence, population mismatch or unclear source support beside the relevant page.

Repeated papers appear under more than one technique on purpose. **Only the first occurrence of each paper is linked.** Later occurrences are deliberately left as plain-text references, so an unlinked paper tells you that the same paper appeared earlier in this reading order. After a paper has been read once, later appearances are reminders to re-check the relevant section.

## What this guide does not establish

This list tells the reviewer **which papers the current diagnostic pages rely on and the order in which to read them**. It does not prove that the present source set is complete. A final evidence review for an individual technique should still ask whether newer validation studies, replications, systematic reviews, guideline updates or contradictory findings exist beyond the papers currently cited here.
