## Original list: nine entries, nine detailed pages

Each entry in the original symptom list has one page, in the same order. There are no additional numbered techniques or supplementary pages in this expansion. The last two entries discuss uncertain specialist options; inclusion is not a recommendation or proof of efficacy. These are selectable approaches, not a nine-step programme.

1. **Positive explanation using preserved vision:** [Positive Explanation of Preserved Vision and Follow-Up](01-positive-explanation-and-follow-up.md).
2. **Notice brief examples of better vision:** [Noticing Briefly Better Vision Without Repeated Testing](02-noticing-briefly-better-vision.md).
3. **Orthoptist-guided visual feedback:** [Orthoptist-Guided Visual Feedback](03-orthoptist-guided-visual-feedback.md).
4. **Graded visual tasks:** [Graded Visual Tasks Linked to Daily Life](04-graded-visual-task-practice.md).
5. **Practise an answer rather than waiting for certainty:** [Supported Visual Choice Without Waiting for Certainty](05-supported-choice-without-certainty.md).
6. **Graded light exposure for photophobia:** [Photophobia: An Agreed Light and Protection Plan](06-photophobia-light-and-protection-plan.md).
7. **Treat coexisting conditions:** [Treatment of Coexisting Eye, Migraine and Neurological Conditions](07-coexisting-eye-migraine-and-neurological-care.md).
8. **Hypnotherapy or therapeutic suggestion:** [Hypnotherapy and Transparent Therapeutic Suggestion](08-hypnotherapy-and-therapeutic-suggestion.md).
9. **Specialist feedback or non-invasive brain stimulation:** [Advanced Visual Feedback and Non-Invasive Brain Stimulation: Specialist Review](09-advanced-feedback-and-brain-stimulation-review.md).

The [history audit](../../../docs/project/recovery-technique-history-audit.md#functional-visual-symptoms) records the baseline and mapping. Safety, flare response and continuing access are covered in the [overview](../08-functional-visual-symptoms.md) and within each detailed page.

The main literature addresses functional visual loss. It must not be applied automatically to double vision, eye-movement disorders, visual snow or all photophobia. Treatment evidence remains limited. Symptoms, disability, needed protection and access supports are real whether or not visual practice helps.
